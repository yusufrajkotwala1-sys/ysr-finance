Firebase Collections used by this app
users — one document per user (uid as doc ID): name, email, role
transactions — one document per transaction: type, date, amount, category, description, createdBy, createdAt, updatedAt
budgets — one document per category/month budget: month (YYYY-MM), category, amount
payment_templates — recurring payment setup: payee, amount, dueDay, category, description, active
payment_records — monthly completion tracking: templateId, month, paid, paidDate, paidBy
settings/categories — single document with two arrays: income[ ], expense[ ]
